### Состав и назначение разработанной документации

В ходе разработки проекта структурированной кабельной системы предприятия был сформирован комплект документации, предназначенный для определения архитектуры кабельной инфраструктуры, размещения телекоммуникационного оборудования, организации кабельных соединений и обеспечения возможности последующего технического обслуживания системы.

Документация включает пояснительную записку, структурные схемы, планы размещения оборудования и кабельной инфраструктуры, систему маркировки, спецификацию оборудования и материалов, а также таблицы и журналы коммутации.

<b>Пояснительная записка</b> - содержит описание назначения и целей проектируемой СКС, характеристику объекта, обоснование выбранной структуры кабельной системы, принципы размещения телекоммуникационных кроссов и принятую систему маркировки компонентов. Документ обеспечивает общее понимание проектных решений и устанавливает основные принципы построения и администрирования СКС (с содержанием документа можно ознакомиться [здесь](../document/EnterpriseSCSproject.pdf)).

<b>Приложение № 1. Схема расположения зданий предприятия</b> - Схема предназначена для отображения пространственного расположения зданий предприятия и определения их взаимного расположения в рамках проектируемой сетевой инфраструктуры. Используется для определения взаимосвязей между объектами, планирования организации магистральных линий связи и формирования общей структуры сети передачи данных предприятия (с содержанием приложения можно ознакомиться [здесь](../document/Building-layout-plan.pdf)).

<b>Приложение № 2. Поэтажные планы зданий предприятия</b> - Поэтажные планы предназначены для отображения планировочной структуры зданий с указанием расположения помещений, рабочих мест, информационных розеток и телекоммуникационного оборудования. Используются для определения мест размещения точек подключения пользователей, планирования прокладки горизонтальных кабельных линий и обеспечения возможности идентификации элементов кабельной инфраструктуры при монтаже и эксплуатации ЛВС (с содержанием приложения можно ознакомиться [здесь](../document/floor-plans.pdf)).

<b>Приложение № 3. Общая топология локально-вычислительной сети предприятия</b> - Схема предназначена для отображения общей архитектуры ЛВС предприятия, включая основные сетевые узлы, активное сетевое оборудование, серверные компоненты и линии связи между ними. Используется для определения структуры взаимодействия элементов сети, анализа организации передачи данных, выявления взаимозависимостей между сетевыми сегментами и обеспечения возможности дальнейшего развития и модернизации инфраструктуры (с содержанием приложения можно ознакомиться [здесь](../document/Enterprise-local-area-network.pdf)).

<b>Приложение № 4. Схема телекоммуникационного шкафа с сетевым оборудованием</b> - Схема предназначена для отображения состава, взаимного расположения и порядка монтажа сетевого оборудования в телекоммуникационном шкафу. Содержит сведения о размещении коммутационных панелей, коммутаторов, кабельных организаторов, устройств электропитания и других предусмотренных компонентов. Используется при выполнении монтажных работ, организации коммутационных соединений, проверке правильности размещения оборудования и последующем техническом обслуживании (с содержанием приложения можно ознакомиться [здесь](../document/Telecommunications-cabinet-with-network-equipment.pdf)).

<b>Приложение № 5. Схема телекоммуникационного шкафа с сетевым и серверным оборудованием</b> - Схема предназначена для отображения состава и компоновки сетевого и серверного оборудования, размещаемого в телекоммуникационном шкафу. Используется для определения монтажных позиций оборудования, планирования его размещения и подключения, организации кабельных соединений, а также обеспечения удобства эксплуатации и технического обслуживания установленного оборудования (с содержанием приложения можно ознакомиться [здесь](../document/Telecommunications-cabinet-with-network-and-server-equipment.pdf)).

<b>Приложение № 6. Журнал коммутации магистральной кабельной системы</b> - Журнал предназначен для документирования соединений магистральной кабельной системы, обеспечивающей связь между зданиями, этажами и основными телекоммуникационными узлами предприятия. Содержит сведения об идентификаторах кабельных линий, точках начала и окончания соединений, используемых кабелях и соответствующих элементах коммутации. Используется для учёта магистральных соединений, контроля изменений кабельной инфраструктуры и локализации неисправностей в процессе эксплуатации ЛВС (с содержанием приложения можно ознакомиться [здесь](../document/Backbone-cabling-system-connection-log.pdf)).





Приложение № 7. Журнал коммутации горизонтальной кабельной системы

Журнал предназначен для учёта и документирования горизонтальных кабельных линий, обеспечивающих подключение информационных розеток рабочих мест и других пользовательских точек к коммутационным панелям телекоммуникационных шкафов. Содержит сведения об идентификаторах кабельных линий, расположении информационных розеток, соответствующих помещениях и номерах портов коммутационных панелей. Используется для идентификации пользовательских подключений, организации коммутации и обеспечения эффективного технического обслуживания кабельной системы.

Приложение № 8. Журнал соответствия портов коммутационных панелей портам коммутаторов

Журнал предназначен для документирования соответствия портов коммутационных панелей физическим портам активного сетевого оборудования. Содержит сведения о номерах портов коммутационных панелей, соответствующих портах коммутаторов и, при необходимости, назначении сетевых подключений. Используется для идентификации коммутационных соединений, определения маршрута подключения пользовательских устройств к активному сетевому оборудованию, выполнения работ по перекоммутации и диагностике неисправностей ЛВС.
